# 新店溪及景美溪匯流口護岸及景觀改善工程 3D 模型

依「新店溪及景美溪匯流口護岸及景觀改善工程 細部設計圖（113 年 10 月）」與竣工測量點建立的 3D 模型，包含互動檢視器與可匯入 CAD／BIM 軟體的 OBJ 模型。

**線上檢視：** https://hankwang0220-debug.github.io/buildmodeltest/

## 內容

| 路徑 | 說明 |
|---|---|
| `viewer/index.html` | 互動 3D 檢視器（單一檔案，用瀏覽器開啟即可，需連網載入 three.js） |
| `model/model.obj`、`model.mtl` | OBJ 模型，含現況與設計地形、水面、丁壩、堤防、高燈、喬木 |
| `model/texture.jpg` | 地形貼圖：平面及鋪面配置（L-06） |
| `model/texture_planting.jpg` | 地形貼圖：植栽配置（L-09） |
| `scripts/` | 建模流程腳本（Python） |
| `data/` | 配準參數、OCR 判讀結果與模型資料（JSON） |

## 座標系統

- 平面：TWD97（TM2 121°），單位公尺
- OBJ 為 Z 軸向上，並平移以避免浮點精度問題：
  - X = TWD97 E − 303800
  - Y = TWD97 N − 2765600
  - Z = 高程（m）
- 檢視器中點擊地面可直接讀取 TWD97 座標、現況與設計高程

## 點雲模式（以實測為準）

圖說與現場會有差異，因此高程與位置以 2025.08 竣工測量點為準：

- 測點 4 m 範圍內的 L-03 圖面高程點不採用，地形以實測點優先。
- 每個測點標註圖說在同位置的物件（設計鋪面、設計綠地、丁壩、球場、堤防等），並記錄設計高程與施工前（L-03）高程。
- 檢視器切到「點雲（實測）」後，可依實測高程、圖說物件、步道偏離、與設計高程差或測點代碼著色；點擊任一點可查詢。

比對結果（步道點 1,933 點）：

| 項目 | 結果 |
|---|---|
| 落在設計鋪面上（1 m 內） | 1,709 點（88%） |
| 偏離 1–2 m | 107 點 |
| 偏離 2 m 以上 | 106 點，主要在 C／E 區交界與 F 區局部，代表實際步道與圖面不同 |
| 實測與設計高程差 | 平均 −0.07 m，絕對值中位數 0.05 m |

## 已知限制

- 設計地形僅由約 100 個設計標註點推得，非完整描繪等高線；模型淨土方約 −3,100 m³，圖說 L-10 為 −6,136 m³，不可用於數量計算。
- B、D 區沒有步道測量點可供核對，配準僅靠影像比對。
- 約 150 棵喬木已定位，其餘樹號未能判讀。
- 引水道水面以 WS 標高點連線近似。
- 本儲存庫不含原始圖說掃描檔與測量原始檔；重新執行 `scripts/` 需自備這些資料。

## 重建流程（需原始圖說）

1. `register2.py` → `register3.py` → `refine.py`：分區圖配準（產生 `data/zoneT.json`）
2. `ocr_spots.py`、`ocr_design.py`、`ocr_trees.py`、`ocr_labels.py`：判讀高程點、設計標高、喬木與高燈
3. `build.py`、`build2.py`：建立地形、貼圖與模型資料
4. `make_html.py`、`make_obj.py`：輸出檢視器與 OBJ

需要的套件：`pillow numpy scipy opencv-python-headless rapidocr_onnxruntime ezdxf`
